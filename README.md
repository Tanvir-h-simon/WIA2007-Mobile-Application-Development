# WIA2007 Mobile Application Development (University of Malaya)

This repository contains materials related to the course **WIA2007 Mobile Application Development**, offered at the University of Malaya.

This course provides an understanding on the categories, development framework and lifecycle of typical mobile applications. Besides, relevant GUI components and its event handling, services and libraries are introduced, including location-aware service, audio, etc. This course also gives practical hands-on on mobile application development with database connection, by considering users, hardware and software requirements as a whole.
